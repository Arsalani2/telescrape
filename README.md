# 📡 TeleScrape

استخراج‌گر (اکسپورتر) **کانال، گروه و چت شخصی تلگرام** با [Telethon](https://github.com/LonamiWebs/Telethon).
متن پیام‌ها، عکس، ویدیو، ویس، موسیقی، فایل و ... را دانلود و در یک پوشه‌ی مرتب (و در صورت تمایل فایل زیپ) ذخیره می‌کند.

طراحی‌شده برای اجرا در **Google Colab (حتی روی گوشی)** و همچنین ترمینال معمولی.

> ⚠️ **توجه:** این ابزار فقط برای تهیه‌ی نسخه‌ی پشتیبان از محتوای خودتان یا محتوایی است که اجازه‌ی دسترسی به آن را دارید. مسئولیت استفاده از آن، رعایت قوانین و [شرایط استفاده‌ی تلگرام](https://telegram.org/tos) با خود شماست.

---

## ✨ امکانات

- 📋 لیست چت‌ها به‌صورت تفکیک‌شده: **کانال‌ها / گروه‌ها / چت‌های شخصی / ربات‌ها**، با قالب `شماره. نام - آیدی عددی`
- 🔎 جست‌وجو و صفحه‌بندی در لیست، و ورود دستی با **آیدی عددی / @username / لینک t.me**
- 🚀 انتخاب چت ← `Enter` ← دانلود کامل از اولین پیام (بدون زیرمنوی اضافه)
- 📱 رابط فشرده و مناسب **صفحه‌ی گوشی** (عرض خطوط قابل تنظیم) و پذیرش **ارقام فارسی/عربی** در همه‌ی ورودی‌ها
- 🔑 خواندن `API ID`، `API Hash` و شماره از **Secrets کولب** (بدون ذخیره روی دیسک)
- 🧊 **سیستم خنک‌سازی** (مکث تصادفی، استراحت‌های دوره‌ای، افزایش خودکار تأخیر بعد از FloodWait) تا درخواست‌های ربات‌گونه به تلگرام نرود
- 🛡️ ضد گیرکردن: timeout و retry برای هر درخواست شبکه، لغو و تکرار دانلودهای متوقف‌شده، اجرای کلاینت در thread جداگانه
- ⏹ توقف تمیز با دکمه‌ی ■ کولب یا `Ctrl+C` (فایل‌های دانلودشده می‌مانند)
- 📦 ساخت خودکار زیپ و امکان دانلود آن در مرورگر
- 💾 ذخیره‌ی اختیاری روی Google Drive

## 🚀 شروع سریع در Google Colab

### ۱. گرفتن API ID و API Hash

1. به [my.telegram.org](https://my.telegram.org) بروید و با شماره‌ی خود وارد شوید.
2. وارد **API Development Tools** شوید و یک اپلیکیشن بسازید.
3. مقادیر `api_id` و `api_hash` را یادداشت کنید.

### ۲. ساخت Secrets در Colab

در نوار کناری Colab روی آیکون 🔑 (**Secrets**) بزنید و این موارد را بسازید و برای هر کدام **Notebook access** را روشن کنید:

| نام Secret | توضیح | الزامی؟ |
|---|---|---|
| `TG_API_ID` | API ID عددی | بله |
| `TG_API_HASH` | API Hash (۳۲ کاراکتر hex) | بله |
| `TG_PHONE` | شماره با کد کشور، مثل `+98912xxxxxxx` | بله |
| `TG_2FA_PASSWORD` | رمز تأیید دو مرحله‌ای (در صورت داشتن) | خیر |

> اگر Secret‌ها ساخته نشده باشند، برنامه مقادیر را به‌صورت دستی از شما می‌پرسد (API Hash نامرئی وارد می‌شود).

### ۳. اجرا

محتوای فایل [`telescrape_v3.py`](telescrape_v3.py) را در **یک سلول** Colab بچسبانید و اجرا کنید. با توجه به خط `#@title`، بالای سلول یک فرم تنظیمات ظاهر می‌شود.

بعد از اجرا:

1. کد ورود تلگرام را وارد کنید (و در صورت نیاز رمز دو مرحله‌ای).
2. از منوی اصلی دسته‌ی دلخواه را انتخاب کنید (کانال‌ها، گروه‌ها، ...).
3. شماره‌ی چت را بزنید، سپس `Enter` برای شروع دانلود.
4. در پایان، خروجی در پوشه و فایل زیپ آماده است.

> 💡 اگر کادر ورودی دیده نشد، به انتهای خروجی سلول اسکرول کنید.

## 💻 اجرا در ترمینال (لینوکس / مک / ویندوز)

```bash
git clone https://github.com/Arsalani2/telescrape.git
cd telescrape
pip install -r requirements.txt

# اختیاری: به‌جای ورود دستی، از متغیر محیطی استفاده کنید
export TG_API_ID=1234567
export TG_API_HASH=0123456789abcdef0123456789abcdef
export TG_PHONE=+98912xxxxxxx
# export TG_2FA_PASSWORD=...

python telescrape_v3.py
```

در ترمینال، مقدار پارامترهای فرم (`LANG`، `SPEED`، `WIDTH` و ...) را مستقیماً از بالای فایل `telescrape_v3.py` تغییر دهید.

---

## ⚙️ پارامترهای فرم (بالای فایل)

| پارامتر | پیش‌فرض | توضیح |
|---|---|---|
| `LANG` | `fa` | زبان رابط: `fa` یا `en` |
| `SPEED` | `normal` | سرعت/خنک‌سازی: `gentle` (آرام) / `normal` / `fast` |
| `WIDTH` | `34` | عرض خطوط (برای گوشی؛ اگر خطوط می‌شکنند کمتر کنید) |
| `PER_PAGE` | `10` | تعداد آیتم در هر صفحه‌ی لیست |
| `USE_DRIVE` | `False` | ذخیره‌ی خروجی‌ها روی Google Drive |
| `SESSION_ON_DRIVE` | `False` | ذخیره‌ی فایل session هم روی Drive (**توصیه نمی‌شود**) |
| `CLEAR_SCREEN` | `True` | پاک‌کردن صفحه بین منوها |

### تنظیمات داخل برنامه (منوی ⚙️)

- دانلود مدیا (روشن/خاموش)
- سقف حجم فایل بر حسب MB (`0` = نامحدود)
- ساخت زیپ
- ساخت فایل `.info` کنار هر مدیا
- سطح خنک‌سازی (آرام / عادی / سریع)
- خروج از حساب و حذف session

## 📁 ساختار خروجی

```
telescrape_data/
├── exports/
│   └── <نام‌چت>_<آیدی>/
│       ├── 000001_Text.txt        # پیام‌های متنی (نام فایل = آیدی پیام)
│       ├── 000002_Photo.jpg
│       ├── 000003_Video.mp4
│       ├── metadata.txt           # اطلاعات هر پیام (نوع، نویسنده، تاریخ UTC، ریپلای، ...)
│       ├── all_texts.md           # همه‌ی متن‌ها و کپشن‌ها در یک فایل مارک‌داون
│       └── LOG.txt                # گزارش اجراها و خطاها
├── zips/                          # فایل‌های زیپ
├── session/                       # session تلگرام (حساس! chmod 600)
├── settings.json
└── dialogs_list.txt               # لیست ذخیره‌شده‌ی چت‌ها (در صورت درخواست)
```

- اجرای دوباره روی همان چت، متن‌ها را بازنویسی می‌کند ولی **مدیای قبلاً دانلودشده را رد می‌کند**.
- در Colab مسیر پیش‌فرض `/content/telescrape_data` است (با ریست runtime پاک می‌شود؛ برای ماندگاری `USE_DRIVE` را روشن کنید).

## 🧊 خنک‌سازی (Cooldown)

برای جلوگیری از محدودشدن حساب، برنامه عمداً کند و «انسانی» کار می‌کند:

| پروفایل | مکث بین هر ۱۰۰ پیام | مکث بعد از هر فایل | استراحت بلند |
|---|---|---|---|
| `gentle` | ۲ تا ۴ ثانیه | ۱٫۵ تا ۳٫۵ ثانیه | ۴۵ تا ۹۰ ثانیه، هر ۴۰ فایل یا ۳۰۰MB |
| `normal` | ۱ تا ۲ ثانیه | ۰٫۶ تا ۱٫۵ ثانیه | ۲۰ تا ۴۵ ثانیه، هر ۸۰ فایل یا ۶۰۰MB |
| `fast` | ۰٫۴ تا ۰٫۸ ثانیه | ۰٫۲ تا ۰٫۵ ثانیه | ۸ تا ۱۵ ثانیه، هر ۱۵۰ فایل یا ۱۵۰۰MB |

در صورت دریافت `FloodWait` از تلگرام، برنامه صبر می‌کند و ضریب تأخیر را تا ۴ برابر افزایش می‌دهد؛ سپس به‌تدریج به حالت عادی برمی‌گردد.
مقادیر این پروفایل‌ها تقریبی‌اند و در محیط واقعی تنظیم دقیق نشده‌اند.

## 🔒 نکات امنیتی

- `API ID`، `API Hash` و فایل **session** مثل رمز عبور هستند؛ هرگز آن‌ها را در گیت‌هاب، چت یا اسکرین‌شات منتشر نکنید.
- برنامه API ID/Hash را **روی دیسک ذخیره نمی‌کند**.
- فایل session به‌صورت پیش‌فرض فقط محلی و با دسترسی `600` ساخته می‌شود.
- خروجی‌های چت (`exports/`) داده‌ی خصوصی‌اند؛ آن‌ها را commit نکنید (فایل `.gitignore` این پوشه‌ها را نادیده می‌گیرد).
- برای باطل‌کردن کامل ورود، از منوی تنظیمات گزینه‌ی **خروج از حساب + حذف session** را بزنید.
- پسوند فایل‌های دریافتی پاک‌سازی می‌شود تا از path traversal جلوگیری شود.

## 🛠️ عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| `Secret پیدا نشد` | Secret را با نام دقیق بسازید و **Notebook access** را روشن کنید، یا مقدار را دستی وارد کنید |
| کادر ورودی دیده نمی‌شود | به انتهای خروجی اسکرول کنید؛ در صورت ادامه، `CLEAR_SCREEN` را خاموش کنید |
| خطوط روی گوشی می‌شکنند | مقدار `WIDTH` را کمتر کنید |
| پیام «محدودیت تلگرام؛ صبر...» | عادی است (FloodWait)؛ منتظر بمانید یا `SPEED` را روی `gentle` بگذارید |
| فضای دیسک کم است | `USE_DRIVE` را روشن کنید یا سقف حجم فایل/دانلود مدیا را محدود کنید |
| آیدی عددی پیدا نشد | آیدی عددی فقط برای چت‌های موجود در لیست شما کار می‌کند؛ از @username یا لینک استفاده کنید |
| لینک دعوت (`t.me/+...`) | پشتیبانی نمی‌شود؛ ابتدا با حساب خود عضو شوید |
